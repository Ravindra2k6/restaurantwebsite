## Where things live, by concern

| If you need to... | Look in |
|---|---|
| Add a new API endpoint | `server/routes/`, `server/controllers/`, wire into `server/routes/index.js` |
| Add a new database field | `server/models/` -- then update the relevant controller and any admin form |
| Change how a page looks on the customer site | `client/src/pages/<Page>/<Page>.jsx` and its component(s) |
| Add a new admin management module | `admin/src/pages/<Module>/`, `admin/src/services/`, wire into `admin/src/routes/AppRoutes.jsx` and `admin/src/utils/constants.js` (sidebar) |
| Change email wording | `server/utils/emailTemplates.js` |
| Change SEO structured data | `client/src/utils/schemas.js` |
| Add a translation string | `client/src/i18n/translations.js` |
| Adjust security/rate limits | `server/middleware/rateLimiter.js`, `server/app.js` |
| Change the sitemap's included pages | `server/controllers/sitemapController.js` |
