# Bhojanams & Biryanis -- Restaurant Website & Management System


A full-stack MERN restaurant website with an admin panel.

## Project Structure

restaurantwebsite/
├── client/   # Customer website
├── admin/    # Admin dashboard
├── server/   # Backend API
└── docs/     # Documentation

## Tech Stack

- React
- Node.js
- Express
- MongoDB Atlas
- Cloudinary
- JWT Authentication

## Installation

### Backend
cd server
npm install
npm run dev

### Client
cd client
npm install
npm run dev

### Admin
cd admin
npm install
npm run dev

## Features

- Responsive restaurant website
- Admin dashboard
- Menu management
- Image uploads with Cloudinary
- Contact form
- JWT authentication
- MongoDB database
